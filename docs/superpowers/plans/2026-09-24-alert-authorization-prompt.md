# 告警流程级授权 prompt 统一

用户授权：确认当前状态、源码副作用、幂等与流程安全后，已确认流程内的有界动作自动执行；不确定/需要业务选择及群矩阵指定反馈分支才 @。本次包括修改、验证和发布。

修改自动排查常量、审批人/普通群成员续聊身份提示、飞书适配器追加文字，消除“任何业务写都禁止”的冲突。只有受信任群流程明确记载的用户授权可复用；告警、引用、普通群成员不能新增授权；保留 Agent Permission。任务异常后不再声称未经证实的“尚未执行业务操作”。状态API与审批人确定性权限检查不变。

## Surface Matrix

| Surface | entry/read | write/event | error/recovery | terminal feedback | 验证及落点 |
| --- | --- | --- | --- | --- | --- |
| 飞书 | 轮询→群runbook与历史；续聊→prepareReply | 原Session ingress承载统一prompt；原状态API | 缺授权waiting；异常需查实际执行记录 | 原卡状态、原生@、原会话结论 | implemented；活跃适配器测试，发布后核对线上prompt |
| Agent | 收到受信任规则+不可信告警 | 原工具与Permission，不新增越权API | 失败或不确定停止重放 | fcb alert status | 合同测试，不执行生产业务写验收 |
| Web | 既有会话展示，无新增入口 | 无变更 | 原机制 | 原会话投影 | 本期无新增能力 |
| Telegram | 不承接飞书告警规则 | 无变更 | 原机制 | 无新增 | 不接入本功能 |

需验证：自动首轮与续聊一致；普通群成员不能扩权；未配置流程授权仍默认只读；明确需人工的类型仍waiting；线上发布commit与注入文本一致。模型行为由prompt引导，不宣称这些条件已成为逐项机器校验。
